# About Page Photo Readiness

Status: publication guardrail for future personal photography.

The About page currently publishes one approved portrait. It intentionally does
not present an empty gallery, stock photography, generated documentary images,
or photographs whose people, places, dates, and permissions have not been
verified.

## Recommended future photo set

| Slot | Purpose | Minimum source | Required verification |
| --- | --- | --- | --- |
| Portrait | Recognizable personal introduction | 1600 × 1600 px | Pacifique approves the image and crop |

## Acceptance checklist

- Use an original photo or a photo with documented permission.
- Obtain explicit consent from every identifiable third party or crop them out.
- Remove EXIF location metadata before publication.
- Check backgrounds for addresses, badges, screens, documents, plates, and names.
- Write a factual bilingual caption with equivalent meaning in English and French.
- Describe meaningful visual information in concise alternative text.
- Use an empty `alt` attribute only when the adjacent caption conveys everything.
- Export responsive WebP/AVIF variants at sensible widths; retain the private source.
- Declare intrinsic width and height to prevent layout shift.
- Do not publish real-time locations, routines, home details, or precise coordinates.

## Suggested responsive derivatives

- `*-640.webp` for narrow/mobile layouts.
- `*-960.webp` for standard content layouts.
- `*-1440.webp` for high-density and wide layouts.

Add a public photo slot only after both localized captions, alt text, consent,
privacy review, optimized derivatives, and visual QA are complete.
